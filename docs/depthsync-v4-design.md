# DepthSync V4.1 端侧算法设计说明

## 1. 方案结论

V4.1 使用 Live Photo 拍照时刻的 DAv2-Large 深度作为锚点，把 VDA-S streaming 视频深度映射到照片值域。全局单调 LUT 仍是稳定基线；局部增强层使用双向光流建立可信对应，再拟合低分辨率 scale/shift 参数。照片深度和照片残差不会直接 warp 成最终输出，因此遮挡或错流只会降低局部置信度，不会覆盖 VDA 原有结构。

64 节点用于提高锚帧非线性映射的表达上限；`8×12` 参数场只表达低频局部尺度差异，不承担细节重建。全部参数在拍摄完成后的准备阶段生成，播放阶段仅查表和采样参数场。

## 2. 输入与中间数据

| 数据 | 规格 | 说明 |
|---|---|---|
| 视频深度 | `T×Hv×Wv`，FP16/FP32 | disparity，值越大越近；验证为 `T=90` |
| 照片深度 | `Hp×Wp`，FP16/FP32 | 配准并缩放到视频深度坐标 |
| 锚帧索引 | int | 验证为第 45 帧 |
| 人脸框 | 4 个归一化坐标，可选 | 只影响采样和全局 offset，不是分割 mask |
| 工作 LUT | `T×64×2`，FP32 | Python 原型输出；端侧建议 FP16 |
| 相邻双向光流 | `2×(T-1)×Hf×Wf×2`，FP16 | 准备阶段使用；验证为 `144×256` |
| 光流置信度 | `2×(T-1)×Hf×Wf`，FP16 | 前后向一致性、越界和遮挡可靠度 |
| 局部参数 | `T×8×12×4`，FP16 | delta-scale、offset、confidence、guide-depth |

光流和照片深度只在准备阶段读取。端侧若已有编码 MV，可作为小型光流的全局运动初值；人物非刚性运动仍以小型光流为准。

## 3. 锚帧 RGB/深度配准

1. 将照片 RGB 与视频锚帧 RGB 缩放到不超过 640 边长。
2. 首先计算恒等映射的鲁棒亮度误差；验证数据只是同一帧的不同分辨率版本时直接保持恒等映射。
3. 只有恒等误差明显时才运行 ECC affine；尺度限制在 `[0.9,1.1]`，平移不超过画面的 8%。
4. 仿射配准至少降低 8% 亮度误差才被接受，否则回退恒等映射。
5. 输出 video-pixel→photo-pixel 归一化采样网格，用同一网格映射照片深度。

## 4. 全局锚帧映射

1. 从锚帧视频深度与照片深度提取最多 16384 个确定性样本。
2. 检测并排除占比较大的无效底值平台，避免场景 12 中大量零值主导拟合。
3. 计算配对样本的秩相关性。相关性可靠时拟合配对单调 LUT；空间对应冲突时使用无对应分位映射。
4. 对 `8/16/32/64` 个有效节点分别拟合，输出执行 isotonic regression，保证深度顺序不翻转。
5. 以配对误差、输出分布误差和复杂度惩罚联合打分；鲁棒 affine 也作为候选参与竞争，只有确实改善时才采用复杂 LUT。
6. 最优曲线统一重采样为 64 节点定长格式。

锚帧输出为 `Y_k = LUT_k(D_k)`；支持不足时显式记录回退原因，不静默输出错误映射。

## 5. 全局逐帧自适应稳定

逐帧处理先判断是否需要修正 VDA 自身的值域漂移：

- 若锚帧 VDA/DAv2 空间排序相关性可靠，则允许分布稳定；
- 若原始 VDA 相邻帧分位形状 P95 跳变超过阈值，也允许分布稳定；
- 两者均不满足时，整段固定复用锚帧 LUT，优先保护时域一致性。

普通序列只用 16 个分位控制点估计 `frame→anchor` 映射，再与 `anchor→photo` LUT 复合并定长化到 64 节点。相对固定锚点 LUT 的修正限制在照片鲁棒值域的 15% 内。检测到强烈模型闪烁时，准备阶段临时使用 64 个控制点并关闭该限幅，以恢复足够的校正能力。

对于 05 一类大面积近景遮挡，整幅深度直方图的突变不代表模型尺度突变。准备阶段计算相邻帧归一化分位形状距离；强闪烁序列中若距离超过阈值，则当前帧冻结上一帧 LUT，不使用被遮挡占比污染的全图分位重新估计。该门控只改变全局参数，最终仍没有空间 mask 或融合边界。

锚帧附近按距离渐进解锁分布修正，锚帧本身保持照片拟合结果，避免第 45→46 帧发生参数状态切换。每一帧仍只有一条全图共享的单调曲线，不存在位置相关参数。

## 6. 光流引导的局部参数场

### 6.1 当前帧到锚帧的对应

SEA-RAFT-S 在 144×256 RGB 上计算相邻帧双向光流。准备阶段从锚帧向前、向后复合相邻流，生成每帧到锚帧的归一化坐标和轨迹置信度。复合置信度采用轨迹最弱链路和90帧半衰期，不把几十个概率直接相乘；场景切换、越界或低可信轨迹被置零。

光流只用于生成样本对：

`(V4.1全局输出(t,p), photo_depth(anchor, W(t→anchor,p)))`

最终输出不会直接混入被 warp 的照片深度。

### 6.2 局部拟合

每帧使用 `8×12` 重叠窗口。窗口内使用空间高斯权重、光流置信度、VDA 深度相似度和深度边缘权重，鲁棒拟合：

`Dlocal = (1 + delta_scale) × Dglobal + offset_norm × photo_range`

- `delta_scale` 限制在 ±0.08；
- `offset_norm` 限制在照片鲁棒值域的 ±0.12；
- 单像素最终修正限制在照片鲁棒值域的 ±0.16；
- 拟合收益不足时置信度连续降到0，而不是在相邻帧间硬开关。

### 6.3 时域联合正则

前后帧参数先沿稠密光流搬到当前帧，再进行5轮对称联合平滑。只有当前帧本来存在直接对应证据的节点参与，不能仅靠历史参数填充新暴露背景。最后从锚帧向两侧施加逐轨迹速度限制：相邻帧 delta-scale 变化不超过0.012，offset_norm变化不超过0.012，confidence变化不超过0.08。

### 6.4 两级安全门

准备阶段尝试 `1.0/0.75/0.5/0.25/0` 五档局部强度。使用同一稠密光流计算运动补偿时域误差，选择满足以下条件的最强档：

- 时域 P95 不超过 V4.1 的 `1.15× + 0.00025`；
- 任一内帧新增误差不超过照片鲁棒值域的0.002。

如果有人脸框，再单独为脸部光流轨迹选择保护强度。保护范围向外扩一个参数节点，避免邻近背景节点通过双线性插值污染人物边缘。该机制不需要人物分割 mask。

## 7. 播放阶段与参数包

每像素先执行64节点分段线性 LUT，再从局部网格的4个邻近节点进行深度引导插值，执行一次乘加。播放阶段不读取照片，不运行模型、MV、光流或照片 warp。

| 参数 | FP16 大小（90 帧） |
|---|---:|
| 每帧 LUT x/y，`90×64×2` | 22.5 KiB |
| confidence/flags/header | 小于 0.5 KiB |
| 局部4通道，`90×8×12×4` | 67.5 KiB |

完整参数包约91 KiB/Live Photo。播放时只需加载当前帧的 LUT 和 `8×12×4` 局部参数（768 B FP16）。Python原型局部应用约10 ms/帧；端侧 C++/NEON/GPU纹理采样需重新测量，准备阶段光流与拟合不计入播放耗时。

## 8. 回退与质量门控

| 条件 | 行为 |
|---|---|
| 配对对应可靠 | affine 与 8/16/32/64 节点配对 LUT 竞争 |
| 配对相关性不足 | 分位 LUT 与原始映射比较，只有改善才采用 |
| 某帧有效分布不足 | 复用锚帧 LUT |
| 构图变化且无明显模型闪烁 | 关闭逐帧分布修正，固定锚帧 LUT |
| 强烈 VDA 分布闪烁 | 64 控制点完整校正 |
| 相邻帧出现大面积遮挡突变 | 冻结上一帧 LUT，待分布恢复后继续估计 |
| 任意 LUT 输出 | 强制单调不减 |
| 光流遮挡、越界或场景切换 | 局部 confidence=0，逐像素回退全局 LUT |
| 局部参数变化过快 | 沿光流轨迹限幅 |
| 整段局部时域超预算 | 自动降低局部强度，最差回退0 |
| 人脸邻帧一致性回退 | 只降低脸部轨迹强度，保留背景收益 |

## 9. 验证说明

每组取3秒、30 fps、90帧，照片锚点使用DAv2-Large。评估同时保留原始VDA、V4.1全局LUT和局部增强结果，四联视频集中到 `results/<run>/compare_videos/`。

本次同一版本的20组离线结果：

- 20/20组的局部参数场都进一步降低了V4.1锚帧 NMAE；中位绝对降幅0.00963，平均降幅0.00999；
- 局部阶段相对V4.1的时序 P95 增量中位数0.000009，P90为0.000168，最大0.000518；
- 人脸切换误差的中位改善为0.000209；个别无精确分割mask且手/脸遮挡明显的片段仍可能轻微回退，因此人脸轨迹保留独立强度门控；
- Python原型局部准备阶段中位307 ms/帧、播放应用阶段中位12.95 ms/帧；这不是端侧性能结论。要满足拍摄后1–2秒准备预算，需使用NPU/GPU版小光流及C++/NEON参数拟合；
- 当前验证文件中全局与局部参数合计中位113.6 KiB；端侧将定长LUT和局部场统一量化为FP16后目标约91 KiB/Live Photo。

验证没有真实深度 GT；锚帧/切换指标衡量与照片深度的一致性，时序指标衡量运动补偿后的相邻帧变化，最终结论仍以固定值域深度视频为准。
