# DepthSync V4 端侧算法设计说明

## 1. 结论

V4 使用 Live Photo 照片时刻的高质量 DepthPro disparity，监督一条全局单调映射，把 Video Depth Anything Small streaming 深度对齐到照片值域，同时保留视频模型已有的时域稳定性。

默认路径不使用任何运行时空间修正：

- 不传播照片残差图或照片目标层。
- 不保存、warp 或融合区域标签。
- 不需要人物分割 mask。
- 所有像素使用同一条全局单调 LUT，不会由算法引入空间边界、轮廓拖影、网格或分层缝隙。
- block MV 只在拍摄后的参数准备阶段约束逐帧全局参数，播放阶段不需要 MV。

此前实验的锚帧区域标签方案在 01 中暴露了结构性问题：全局平移使第 0 帧标签右移约 11 像素，左侧露出未修正竖条、右侧越过真实墙面形成黑缝；第 60 帧常量区域 offset 在墙体轮廓处硬截断，形成“7”形分层。即使做形态学清理也无法消除“固定空间区域与当前帧边界不完全一致”的根因，因此默认路径已撤下空间区域修正。

## 2. 输入与约定

| 数据 | 规格 | 约定 | 使用阶段 |
|---|---|---|---|
| 视频深度 | `T×Hv×Wv`，FP16/FP32 | disparity，值越大越近 | 参数准备、播放 |
| 照片深度 | `Hp×Wp`，FP16/FP32 | 配准到视频深度坐标 | 仅参数准备 |
| 锚帧 | 标量 `k` | 验证为第 45 帧 | 参数准备 |
| block MV | `T×GmH×GmW×2` | 按宽高归一化，可带 confidence | 仅参数准备 |
| 人脸框 | 4 个归一化坐标，可选 | 采样与模型选择加权，不是分割 mask | 仅参数准备 |

验证素材为 90 帧、30 fps；block MV 使用 `32×18` 稀疏 LK 网格模拟。产品实现优先复用编码器或 ISP 已有 MV。

## 3. 锚帧全局映射

### 3.1 鲁棒样本

1. 将照片 disparity 配准并缩放到视频深度坐标。
2. 只保留有限值和较低梯度位置，降低照片细节与视频粗边缘错位的影响。
3. 做确定性固定采样；有人脸框时，约 30% 样本来自人脸 ROI，其余来自全图。
4. 用分位数、MAD 和鲁棒 affine 拒绝 gross mismatch。

### 3.2 自适应 LUT 复杂度

分别拟合 8、12、16 个有效节点的分段线性单调 LUT：

1. 按视频 disparity 排序并等量分箱。
2. 每个分箱取视频/照片加权中位数。
3. 对输出节点执行 isotonic regression，保证单调不减。
4. 计算锚帧全图 NMAE；有人脸框时再加人脸 ROI NMAE。
5. 选择组合误差最小的候选。
6. 将选中形状重采样到定长 16 节点。

这样 01、03 可以使用更高表达能力，02 自动选择等效 8 节点形状，避免高节点 LUT 对局部分布过拟合。

锚帧输出为：

`B_k = LUT(D_k)`

若有效对应不足，则回退到鲁棒 affine。

## 4. 时域参数传播

LUT 的非线性形状在整段视频中固定。对第 `i` 帧：

1. 先计算 `LUT(D_i)`。
2. 通过 block MV 在当前帧与相邻已处理帧之间建立稀疏对应。
3. 只拟合小幅 `scale_i` 与 `offset_i`。
4. 从锚点分别向前、向后扫描，并对参数做置信度加权平滑和逐帧限幅。
5. 锚点附近保持锁定，再渐进解锁，避免参数状态切换。

最终输出：

`Y_i = scale_i × LUT(D_i) + offset_i`

映射只依赖 disparity 值，不依赖像素位置，因此不存在区域 mask 边界。

## 5. 播放阶段

每像素只需：

1. 在 16 节点 LUT 中定位区间。
2. 一次线性插值。
3. 一次逐帧 scale/offset。

播放阶段不读取照片深度、不使用 block MV、不做形态学操作、不做空间 warp 或区域融合。

## 6. 参数包

| 参数 | 推荐格式 | T=90 大小 |
|---|---:|---:|
| 共享 LUT x/y，`16×2` | FP16 | 64 B |
| 逐帧 scale/offset，`90×2` | FP16 | 360 B |
| 版本、范围、置信度/回退位 | 定点/整数 | 约 64–128 B |

推荐端侧参数包约 0.5–0.6 KiB/Live Photo。Python 原型为了接口和诊断方便重复保存了逐帧 LUT；生产序列化只保存一份共享 LUT。

播放阶段除输出图外只需要 LUT 和当前帧两个标量，额外工作内存可忽略。

## 7. 回退策略

| 条件 | 回退 |
|---|---|
| 照片/视频有效对应不足 | 鲁棒 affine |
| 某帧 MV 对应不足 | 复用相邻帧 scale/offset |
| 参数变化超过限幅 | 裁剪到上一帧允许范围 |
| 无 block MV | 固定锚帧 LUT，不做逐帧修正 |

## 8. 三段验证结论

每段素材取 3 秒、30 fps、90 帧，锚帧为第 45 帧。详细数值见 `reports/validation.md`。

- 01：锚帧 NMAE `0.1734 → 0.0613`；主体时序 P95 `0.0039 → 0.0018`。
- 02：自动选择低复杂度 LUT；人脸切换 `0.0246 → 0.0225`，主体时序 P95 `0.0052 → 0.0039`。
- 03：锚帧 NMAE `0.0463 → 0.0311`；主体时序 P95 `0.0035 → 0.0024`。
- 01 第 0 帧左右竖条、右侧黑缝以及第 60 帧“7”形轮廓，在关闭空间区域修正后不再存在。

验证没有真实深度 GT；锚帧指标衡量与 DepthPro 的相对一致性，时序指标衡量 block MV 补偿后的相邻帧变化。
