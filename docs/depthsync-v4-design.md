# DepthSync V4 端侧算法设计说明

## 1. 目标与设计边界

V4 用 Live Photo 照片时刻的高质量 DepthPro disparity，校正 Video Depth Anything Small streaming 深度的尺度，同时优先保持视频模型已有的时域稳定性。

V3.x 的主要问题不是参数不够精细，而是把照片锚帧的空间目标或残差传播到了其他时刻。人物运动后，固定照片掩码、锚帧残差或锚帧人物区域会留在背景上，表现为轮廓拖影、网格、墙面分层和单帧跳变。V4 因此采用以下硬约束：

- 照片深度只用于估计参数，不作为播放阶段的逐像素目标。
- 不传播照片残差图，不保存照片目标层。
- 不要求人物分割 mask；人物和不可靠区域自动回退到全局 LUT。
- 局部修正只允许作用于全片高置信静态、面积足够大的视频深度区域。
- 无可靠静态区域时退化为全局 LUT，不能为了锚帧误差污染时域。

## 2. 输入、坐标和数值约定

| 数据 | 规格 | 数值/坐标约定 | 生命周期 |
|---|---|---|---|
| 视频深度 | `T×Hv×Wv`，建议 FP16 | disparity，值越大越近 | 输入 |
| 照片深度 | `Hp×Wp`，FP16/FP32 | 几何配准到视频深度坐标 | 仅参数准备 |
| 锚帧索引 | 标量 `k` | 验证为 45 | 输入 |
| block MV | `T×GmH×GmW×2` | 位移按宽高归一化，可带 confidence | 参数准备 |
| 人脸框 | 4 个归一化坐标，可选 | 只作前景硬保护，不是人物分割 | 参数准备 |
| 鲁棒范围 | 标量 | 照片 disparity 的 P10–P90 | 参数准备/运行时阈值 |

本项目验证工作域约为 `456×256`，每段 90 帧；block MV 用 `32×18` 稀疏 LK 网格模拟。产品实现应优先复用编码器或 ISP 已有 MV。

## 3. 参数准备流程

### 3.1 全局尺度映射

1. 将照片深度配准并缩放到视频深度坐标。
2. 在锚帧低梯度有效区域做确定性采样；若有人脸框，保留部分人脸样本权重。
3. 用分位数和 MAD 得到鲁棒 affine 初始化。
4. 对 `(视频 disparity, 照片 disparity)` 做分箱中位数和单调回归，生成 8 节点分段线性 LUT。
5. LUT 的非线性形状在整段视频中固定。逐帧只允许小幅 `scale_i`、`offset_i`，并从锚点向前、向后平滑扫描。

基础输出为：

`B_i = scale_i × LUT(D_i) + offset_i`

这条路径覆盖所有像素，也是任意低置信情况的回退路径。

### 3.2 静态可靠性

在 `128×72` 工作网格上累计：

- block MV 幅值与 confidence；
- 去除全局中位变化后的逐像素时序 MAD；
- 3 帧时域中值与全片极差，捕获只在片头或片尾出现的主体；
- 可选人脸框及其扩展区的前景硬保护。

得到静态支持图 `Q`。`Q` 只参与离线筛选，不进入播放阶段。

### 3.3 以视频锚帧划分区域

区域边界必须来自锚帧视频深度，不能来自照片残差：

1. 将 `B_k` 缩放到 `128×72`。
2. 对四邻域做连通，邻接 disparity 差小于照片鲁棒范围的 4% 时合并。
3. 删除面积小于全图 1% 的区域，最多保留 8 个候选。
4. 删除静态支持率低于 65% 的区域。
5. 删除与可选人脸框相交的区域。

最终标签图 `L` 只包含可安全修正的大静态背景。人物、头发、手臂、遮挡边界和不确定背景均为标签 0。

### 3.4 区域标量修正

对每个保留区域 `r`：

1. 计算照片区域中位值 `P_r`。
2. 用 block MV 的高置信中位位移累计全局平移 `shift_i`。
3. 将锚帧标签图平移到第 `i` 帧，在对应区域计算 `median(B_i)`。
4. 得到 `delta_i,r = P_r - median(B_i)`。
5. 对已通过全片静态筛选的区域，逐帧直接锁定区域中位值；以鲁棒范围的 75% 作异常限幅。这样片头不会缓慢追赶锚点，区域中位统计本身用于抑制像素噪声。

区域只保存标量 offset，不保存照片纹理、残差图或逐像素目标。

## 4. 播放阶段

每帧执行：

1. 8 节点 LUT 与逐帧小 affine，得到 `B_i`。
2. 用 `shift_i` 对 `128×72` U8 标签图做最近邻平移。
3. 查表取得每个标签的 `delta_i,r`。
4. 用当前视频深度的 3×3 局部范围生成边缘保护 `E_i`。
5. 输出 `Y_i = B_i + E_i × delta_i,L`；标签 0 的修正恒为 0。

照片深度不参与播放。区域错配时，3×3 视频深度边缘保护会关闭跨前后景修正；当没有可靠区域时，步骤 2–4 可完全跳过。

## 5. 参数包

推荐端侧编码如下：

| 参数 | 推荐格式 | 最坏规格（T=90，R=8） | 大小 |
|---|---:|---:|---:|
| 共享 LUT x/y | FP16 | `8×2` | 32 B |
| 逐帧 scale/offset | FP16 | `90×2` | 360 B |
| 静态区域标签 `L` | U8 | `72×128` | 9,216 B |
| 逐帧区域 offset | FP16 | `90×(R+1)` | 1,620 B |
| 逐帧全局 shift | FP16 | `90×2` | 360 B |
| 版本、范围、区域数 | 定点/整数 | 小于 64 B | ≤64 B |

最坏约 11.4 KiB/Live Photo。若没有可靠静态区域，可省略标签图和区域 offset，参数包约 0.8 KiB。Python 原型为了接口简单重复保存了逐帧 LUT，生产序列化时应只保存一份共享 LUT。

## 6. 端侧计算与内存

播放阶段每像素主要包含一次 8 节点 LUT 插值、一次标签查表、一次加法；启用区域时增加 3×3 min/max 边缘保护。标签 warp 是全局平移，不需要稠密光流。

参数准备阶段不必缓存 90 帧全分辨率 FP32 深度。建议两遍流式实现：

- 第一遍拟合全局 LUT/逐帧 affine，并缓存 `90×72×128` FP16 基础深度，约 1.58 MiB。
- 第二遍累计时域统计、划分区域并生成区域 offset。

除模型本身外，DepthSync 的峰值额外工作内存可控制在约 2 MiB。当前 NumPy 原型以验证正确性为目标，会缓存更多中间结果，不能直接作为端侧内存数据。

## 7. 回退策略

| 条件 | 回退 |
|---|---|
| 照片/视频有效对应不足 | 鲁棒 affine |
| block MV 缺失或低置信 | 固定 LUT，不启用区域修正 |
| 无高置信大静态区域 | 固定 LUT，不保存区域图 |
| 区域落在当前深度边缘 | 当前像素关闭区域 offset |
| 区域 offset 超出合理范围 | 按照片鲁棒范围限幅 |

核心原则是：局部修正是可选增强，全局 LUT 是稳定基线。

## 8. 当前验证结果

三段素材均取 3 秒、30 fps、90 帧，锚帧为第 45 帧。详细指标见 `reports/validation.md`，深度对比视频位于 `results/<scene>/depth_visualization/`。

- 01 自动保留 1 个高置信大静态墙面区域；人物区域不进入局部参数。
- 02、03 没有通过静态可靠性筛选的区域，自动退化为全局 LUT。
- 三段主体时序 P95 均优于 V1 affine 基线。
- V4 不再传播锚帧残差，因此机制上消除了“人物离开后仍留在原位置”的照片残差轮廓。

验证没有真实深度 GT；锚帧误差衡量与 DepthPro 的相对一致性，时序指标衡量 block MV 补偿后的相邻帧变化。
